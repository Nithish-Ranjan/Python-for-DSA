# Python for DSA 🐍

A structured collection of **Python programming, Object-Oriented Programming, Data Structures, Algorithms, and problem-solving implementations** developed through an 11-day learning and practice journey.

The repository starts with Python fundamentals and gradually progresses through OOP, arrays, searching, sorting, linked lists, recursion, backtracking, stacks, queues, and trees. It also includes a complete **AI-Powered Smart Complaint Prioritization and Resolution Management System** as a practical application of the concepts learned.

# 🚀 Complaint Management System

Along with the DSA implementations, this repository contains a practical Python application:

## AI-Powered Smart Complaint Prioritization and Resolution Management System

The system demonstrates how programming, OOP, data structures, databases, and AI-assisted analysis can be combined into a real-world application.

### Key Features

* Complaint registration and management
* Complaint prioritization
* Priority queue based processing
* Role-based access
* Admin functionality
* Technician functionality
* Complaint status management
* SQLite database
* Reporting functionality
* AI-powered complaint analysis
* Local keyword-based fallback analyzer
* Desktop GUI

### Technologies Used

* **Python**
* **Object-Oriented Programming**
* **SQLite**
* **Priority Queue**
* **GUI**
* **Gemini API**
* **Database Management**

### Running the Application

Navigate to the project directory:

```bash
cd ComplaintManagementSystem
```

Install the required dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python main.py
```

An optional Gemini API key can be configured to enable AI-powered complaint analysis.

The application also includes a local keyword-based analyzer, allowing the system to operate without an API key.
