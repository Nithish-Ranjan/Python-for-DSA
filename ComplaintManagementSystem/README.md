# AI-Powered Smart Complaint Prioritization and Resolution Management System

A Python desktop mini-project showcasing OOP, SQLite, priority queues, reporting, role-based access, and optional Gemini-powered complaint analysis.

## Run

1. Install Python 3.10+.
2. `pip install -r requirements.txt`
3. Optionally set `GEMINI_API_KEY` to enable Gemini analysis.
4. Run `python main.py`

Demo accounts: `admin / admin123` and `tech1 / tech123`.

Without a Gemini key, the application uses a transparent keyword-based local analyzer so every feature remains demonstrable offline.
